# Data Usage and Privacy

Privacy policy of the app **Hispetra: Rota AR** (Geo-Naturpark Bergstraße-Odenwald e.V.), German and English, published with
GitHub Pages:

https://geopark-rota-project.github.io/Data-Usage-and-Privacy/

Use this URL as the privacy policy URL in the Google Play Console (and in App Store Connect).

To change the text, edit `index.html` and push to `main`. GitHub Pages publishes it in about one minute.
Update the date ("Stand" / "Effective date") when the content changes.
